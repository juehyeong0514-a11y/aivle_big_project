# 관리자·감독관 시험 정책 권한 분리

## 결정

시험 운영에 직접 필요한 정책은 감독관(조직 관리자)이 담당 조직의 **시험 단위**로 관리한다. 플랫폼 전체에 영향을 주는 기본 설정과 AI 인프라 설정은 ADMIN이 계속 관리한다.

| 기능 | 담당 역할 | 범위 |
| --- | --- | --- |
| 전체 시험 조회 | 감독관 | 배정·승인된 조직, 읽기 전용 |
| 조직·관리자 승인 | ADMIN | 플랫폼 전체 |
| 전역 기본 정책 및 AI 인프라 설정 | ADMIN | 플랫폼 전체 |
| 시험 정책 관리 | 감독관 | 배정·승인된 조직의 시험 |
| 시험 금지사항 관리 | 감독관 | 배정·승인된 조직의 시험 |
| 문제·응시자·초대 관리 | 감독관 | 배정·승인된 조직의 시험 |

## 구현 원칙

- 전역 `systemPolicies`는 ADMIN 전용 API(`/api/admin/policies`)로 유지한다. 초대 링크 만료 시간과 AI 분석 설정은 별도 메뉴로 분리한다.
- 각 시험은 `examPolicies`를 가지며, 새 시험은 전역 정책을 초기값으로 복사한다.
- 감독관 정책 API는 `/api/supervisor/exams/:examId/policies`이며, 서버에서 조직 범위를 검증한다.
- 다른 조직 시험 접근 및 ADMIN 전용 전역 정책 수정은 `403`이어야 한다.

## 화면 구성

감독관 메뉴의 **조직 및 시험 운영** 그룹에 다음을 제공한다.

- 전체 시험 조회
- 시험 관리
- 시험 정책 관리
- 시험 금지사항 관리

ADMIN의 시험 메뉴는 생성·수정 기능이 없는 **전체 시험 조회**로 유지한다.
